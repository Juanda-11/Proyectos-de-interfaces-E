# Contribuir

1. Crea una rama desde `main` (`feat/...`, `fix/...`, `docs/...`).
2. Usa [Conventional Commits](https://www.conventionalcommits.org/es/) en los mensajes (`feat(simulación): ...`).
3. Antes de abrir el pull request ejecuta `npm run check`.
4. Si cambias la interfaz, adjunta capturas; si cambias el contrato con el backend, coordina el cambio en el otro repositorio.
